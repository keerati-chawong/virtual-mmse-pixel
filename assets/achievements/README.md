# รูป Achievement

วางรูปวาดเองเป็นไฟล์ PNG ในโฟลเดอร์นี้ ตั้งชื่อตาม id ของ Achievement แล้วเปิดโปรเจกต์ใน Godot ครั้งหนึ่งให้มัน import
ถ้ายังไม่มีไฟล์ เกมจะวาดเหรียญตราชั่วคราวให้แทน

| ไฟล์ | Achievement |
|---|---|
| `first_run.png` | ก้าวแรกของนักประเมิน |
| `miss3.png` | อาจารย์จะเขกหัวแล้วนะ! |
| `perfect.png` | ตาเหยี่ยว |
| `open_only.png` | ไม่ชี้นำสักคำ |
| `interp.png` | แปลผลเป๊ะ |
| `community.png` | ลงชุมชนครั้งแรก |
| `hard_clear.png` | มือโปรเคสยาก |
| `all_diff.png` | ครบทุกระดับ |
| `shopper.png` | สายแฟชั่นประจำวอร์ด |

ขนาดแนะนำ: สี่เหลี่ยมจัตุรัส เช่น 128×128 หรือ 256×256 (pixel art 32×32 ก็ได้ เกมขยายแบบไม่เบลอ)
ชื่อ คำอธิบาย และรางวัลแก้ได้ที่ `scripts/profile.gd` (ค่าคงที่ `ACH`)
