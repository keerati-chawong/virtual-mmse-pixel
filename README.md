## ▶ เล่นบนเว็บ
**https://keerati-chawong.github.io/virtual-mmse-pixel/** (Chrome / Edge / Firefox บนคอมพิวเตอร์)

อัปเดตเวอร์ชันเว็บ: export ใหม่ (`Godot --headless --path . --export-release "Web"` → ออกไปที่ `docs/`) แล้ว commit + push

## วิธีเปิด
- **เล่นทันที:** ดับเบิลคลิก `play.bat`
- **แก้ไขใน Godot:** เปิด Godot 4.7 → Import → เลือก `project.godot` → กด F5
- **เวอร์ชันเว็บ:** โฟลเดอร์ `../mmse-pixel-web` → ดับเบิลคลิก `play-web.bat` (ต้องมี Python)
  - export ใหม่: `Godot --headless --path . --export-release "Web"`

## ของใหม่ในอัปเดตนี้
- 2 สถานการณ์ (เลือกที่หน้าเมนูเกม)
  - Scenario 1 คุณสมชาย 68 ปี — ให้ความร่วมมือดี
  - Scenario 2 คุณยายสมพร 75 ปี — สับสน ตอบช้า บางครั้งตอบไม่ตรงคำถาม/ขอให้ถามซ้ำ
- ข้อ 5 ทวนความจำ: ผู้ป่วยตอบเรียงหรือไม่เรียงลำดับก็ได้คะแนนหมด (เกณฑ์ + feedback)
- ชุดตัวละคร: ชุดกระโปรงขาวขลิบน้ำเงิน โลโก้คณะพยาบาลศาสตร์ มข. ที่อก
  หมวกพยาบาลไม่มีขีด รองเท้าพยาบาลขาว ถุงเท้าขาว · โลโก้แสดงที่หัวเว็บ/หน้าหลัก

## วิธีเล่น (ปุ่มลัด)
- เลือกคำพูด: คลิก หรือกดเลข **1–9** · ปุ่มการกระทำ (▶): **Space / Enter**
- เปิด/ปิดใบคะแนน: **Tab** · หยุดเกม: **Esc** · คลิกกล่องบทสนทนาเพื่อข้ามตัวอักษรที่กำลังพิมพ์
- ของในฉากที่มีประกาย ✦ กดดูได้ (ปฏิทิน หน้าต่าง ป้ายหอผู้ป่วย)
- ได้ดาว 1–3 ดวงตามความแม่นยำในการบันทึกคะแนน เก็บสถิติดีที่สุดแยกตามผู้ป่วย

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/data.gd` | เนื้อหาทั้งหมด (ข้อสอบ เกณฑ์ สถานการณ์) — แก้ข้อความที่นี่ |
| `scripts/parts.gd` | สุ่มพฤติกรรมผู้ป่วย + feedback ของแต่ละข้อ |
| `scripts/game.gd` | สถานะเกม ผู้ใช้ ประวัติคะแนน (เก็บใน user://) |
| `scripts/pixel.gd` | วาดสไปรต์ pixel ทั้งหมดด้วยโค้ด (พยาบาล ผู้ป่วย ของประกอบ) |
| `scripts/art.gd` | ภาพพื้นหลังฉาก (ห้องผู้ป่วย ทางเดิน หน้าโรงพยาบาล) พร้อมพื้นผิว/แสงเงา |
| `scripts/stage.gd` | ฉาก 320×180 ขยายเต็มจอแบบ nearest + ข้อความไทยซ้อนด้านบน |
| `scripts/sfx.gd` | เสียงเอฟเฟกต์ 8-bit สร้างด้วยโค้ด |
| `scripts/screens/sim_base.gd` | โครงหน้าจอเกม: HUD · กล่องบทสนทนา RPG · คลิปบอร์ดใบคะแนน |
| `scripts/screens/*` | หน้าจอแต่ละหน้า |
| `tools/shots.gd` | เล่นอัตโนมัติทั้งรอบ + ถ่ายภาพ: `Godot --path . -- --shots <dir> [--s2]` |
